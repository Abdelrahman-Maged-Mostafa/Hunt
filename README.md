### 🚀 طريقة التثبيت حسب النظام

<details>
<summary><b>🪟 Windows (اضغط هنا للعرض)</b></summary>

قم بتنزيل ملف التثبيت ثم شغل الأمر التالي في الـ Terminal:
\`\`\`bash
npm install
npm run start-win
\`\`\`

</details>

<details>
<summary><b>🍎 macOS (اضغط هنا للعرض)</b></summary>

قم بفتح الـ Terminal ونفذ الأوامر الآتية:
\`\`\`bash
brew install project-name
project-cli init
\`\`\`

</details>

<details>
<summary><b>🐧 Linux (اضغط هنا للعرض)</b></summary>

استخدم مدير الحزم الخاص بتوزيعتك:
\`\`\`bash
sudo apt update
sudo apt install project-name
\`\`\`

</details>
